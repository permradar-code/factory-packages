## 10. Правила, которые не меняются
- **Ключи** (ElevenLabs, OpenAI, Google) только в переменных окружения или секретах сервера. Никогда не печатать, не писать в файлы и git, не просить в чат.

- Файлы больше 100 MB в git не класть, резать на части по 90 MB (+ `join.ps1`). Через SendUserFile до 30 MB.
- Бюджет: генерацию до $3 на ролик Claude одобряет сам, выше спрашивать. Фильм 2 через API (≈ $84 со всем) пользователь одобрил по факту запуска фабрики.
- Не менять название и превью лонга во время A/B-теста, ничего не накручивать, не перезаливать.
- Во Flow (если вдруг): запросы по одному, x1, пауза 30–60 с, стоп при остатке меньше 150 кредитов (было около 397).
- Комментарии: отвечать в первые дни, хейтеру спокойно и коротко. Под чужими видео не спамить.
