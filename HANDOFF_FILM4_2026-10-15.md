## Грабли и подсказки по инструментам
- `film_asset_skip`/`unskip` — только по одному, не параллельно (гонка теряет изменения).
- `film_redo` игнорирует SKIPPED; `unskip` возвращает старый файл READY → сначала unskip, потом redo картинки.
- `film_dialogue_realign` — по одному, пауза ~30 с (иначе 409). `film_asset_unskip` на dialogue_alignment → 500, не использовать. Если whisper не распознал — владелец слушает, затем `film_dialogue_confirm`.
- `film_package_prepare` отказывает для запущенного проекта → кадры менять через `shot_overrides.json` на сервере (поля `image_prompt_full`, `motion_prompt`, `references`).
- `patch_check`/`patch_apply` — diff против HEAD; файл должен быть не тронут с HEAD (поэтому сначала владелец коммитит). Новый файл — через `/dev/null`.
- `exec_submit` разрешает только `python -m pytest <файлы>`, `git status --short`, `git diff --check`.
- Посмотреть картинку: `film_thumbnail source="img:<id>"` (создаёт `zz_check_*`).
- `film_edit_set`: убрать переопределение визуалов — `{"visuals": null}`.
- Google блокирует кадр, где ребёнок и винтовка вместе — в промптах их разводить.
